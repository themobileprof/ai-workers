n8n is the only public door. The Go process listens on the Docker network at http://agents:8000. That URL is not a browser page. Caddy never publishes /departments.

  1. Open n8n in the desk (iframe of /home) or Telegram/WhatsApp.
  2. Chat prefixes strip the command, then POST JSON to the department path.
  3. Read back status, output_text (what the human sees), and structured_data (what n8n acts on).

Specimen 01 · required body

Every worker, every time

{
  "task_description": "Plain language task.",
  "context_data": {
    "channel": "whatsapp",
    "chat_kind": "dm"
  }
}

context_data must be a JSON object. Empty is {}, never a blank expression. Timeout the HTTP node at 120 seconds.

Specimen 02 · worker reply

{
  "status": "success",
  "output_text": "What the person reads on WhatsApp, Telegram, or email.",
  "structured_data": {
    "task_type": "sales_support"
  }
}

When you add a worker

New department = one extra Go route, one catalog row in docs.go, and a file playbook/{slug}.html. Until that route is called from a published workflow, stamp the page Not wired and leave a later-box with the sample you will write on the day it ships.

When you add a vendor

New third-party tool = one row in agents/internal/admin/integrations.go (env names, n8n credential names, desk keys). The Tools page and the integrations test stay in lockstep. Accounts ids go on Defaults, not in the workflow JSON.

When you add a project

Incubation bets live on Projects, not in workflow JSON. Pass context_data.project (slug) or project_id once n8n starts attaching chats to a bet. Until then, chat is one-shot and the desk row is the memory.
