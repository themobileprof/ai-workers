  1. Sign in. You land on Board.
  2. Add a human on People: name, phone, office seat, then tick only the workers they should run. Ticking a desk is what lets them log in.
  3. Seat a project face or field person on that bet’s Face tab — cofounder or assistant. Seat is not a login. Login is the desk tick.
  4. On a worker: Ask → read the proposal → chat a fix if needed → Accept. Chat never Accepts.
