Data-room clerk. Ops Telegram /file or a dropped PDF. A catalog match files itself; n8n writes Google Drive. Unsure rows stay on Files for Accept. The worker cannot upload, share, or invent a folder.

  1. Create a Google Shared Drive. Paste its id on Defaults → Drive. Bind n8n credential Google Drive.
  2. On ops Telegram, send the file (PDF or photo) with /file, or drop a document in that chat. Caption may name the bet.
  3. If the path is a catalog match, it files. If it is odd, Accept or Turn away on Files. Chat never writes Drive.

Office papers (CAC, TIN, bank letters) use slug themobileprof, not a bet. Academy Telegram and customer WhatsApp do not file. Receipt photos without /file still go to Accounts.
