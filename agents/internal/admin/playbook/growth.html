Front office. Answers customers, drafts info@ replies, and writes social copy. It does not send mail or WhatsApp itself.

  1. WhatsApp 1:1 with no prefix → growth. Or start with /growth.
  2. Telegram ops: /growth Write a LinkedIn post about…
  3. Email: send a real mail to info@themobileprof.com. Customer mail: Growth drafts. Telegram shows the card. /approve sends, /kill drops. A CV / “I am applying” mail goes to HR instead — no draft, no send.
  4. Manual smoke in n8n: Smoke: growth HTTP (smkGrwthHttp0001).

Specimen 01 · sales chat

WhatsApp 1:1: How much is the bookkeeping assistant for a mechanic workshop in Ikeja?

{
  "task_description": "How much is the bookkeeping assistant for a mechanic workshop in Ikeja?",
  "context_data": {
    "channel": "whatsapp",
    "chat_kind": "dm",
    "from": "2348012345678",
    "department": "growth"
  }
}

You should see a short WhatsApp reply. If intent is high, structured_data.record_lead is true and n8n upserts a Zoho Books contact with that phone. Never invented emails.

Specimen 03 · inbound info@

Mail from a human to info@themobileprof.com (not from info@, not subject “n8n smoke”).

Customer mail: Growth drafts a plain-text reply. Email outbox holds one pending draft. Ops Telegram gets the card. First /help the bot so it knows your chat id. /approve sends via Zoho Mail SMTP. A CV / application does not take this path — see HR.
